# Vivian Feature Engineering

Vivian owns this folder. The current contribution is generated by `feature.ipynb`; `features.py` is still the original starter and should not be run to regenerate these six features.

Run the notebook from this folder using the project environment. Its feature-extraction cell exports `outputs/features.csv`, the only file read by model building. The older `outputs/vivian_features.csv` includes exploratory labels and is not consumed by the pipeline. The shared export has 156 rows (f1–f13, recording days 2–13), the two join keys, and these six numeric features:

| Feature (without `vivian__`) | Meaning |
| --- | --- |
| adj_ultradian_amp | Daily mean of the maximum wavelet amplitude across 1–3-hour periods in activity-adjusted CBT. |
| adj_circadian_amp | Daily mean of the maximum wavelet amplitude across 23–25-hour periods in activity-adjusted CBT. |
| adj_mean_h6_12 | Mean adjusted CBT during recording-day hours 6–12, °C. |
| adj_range | Daily maximum minus minimum adjusted CBT, °C. |
| adj_decline_hour | First hour with adjusted CBT below that day's median; this is a first-below-median time, not necessarily the onset of a decline. |
| act_cbt_corr | Daily Pearson correlation between log(1 + activity) and cleaned, unadjusted CBT. |

CBT is interpolated, floored at 35 °C, and clipped to each mouse's full-recording mean ± 3 SD. Signals are averaged into 5-minute bins. Per-mouse regression removes the association with log activity at the current bin and three preceding bins; wavelets use the complete adjusted recording before retaining days 2–13. The Morlet wavelet integration precision is explicitly 10 to reproduce the submitted values across library versions. The lag implementation uses circular shifts at the recording boundary.

These inputs require the complete recording, including future measurements, for **retrospective classification**. Each mouse's extraction is independent of other mice and estrus labels. The shared export is uncentered and leaves missing values for training-fold imputation. The notebook's separate exploratory classifier uses per-mouse centering, so its scores are not directly comparable to the shared model report.

Validate from the repository root with `estrus validate --owner Vivian`. Model building reads the exported CSV without executing this notebook.
