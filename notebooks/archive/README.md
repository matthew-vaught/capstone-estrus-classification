# Historical modeling prototype

`model_prototype.ipynb` is the original, unfinished TensorFlow modeling notebook. Its contents are preserved. It contains placeholder data/target names and uses a generic row-level split, so it is not the current mouse-grouped evaluation and cannot reproduce the shared project's results as supplied.

`requirements.txt` preserves that prototype's separate environment description for historical reference. It is not part of the verified shared-pipeline environment. The active workflow is documented in the root [README](../../README.md) and [modeling guide](../../docs/MODELING.md).
